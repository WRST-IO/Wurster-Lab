**folio.wurst** is a personal portfolio site packaged as a single file. Instead of sending a link that might rot, send the file itself — it opens the same way years from now as it does today.

## What it shows off

- A static, content-heavy site ground into a single `.wurst`
- Signing the file against a domain identity so recipients can verify it's really from you
- Running identically whether it's opened locally or via the Web/CDN runtime
