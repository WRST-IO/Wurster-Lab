**boardz.wurst** is a kanban board. Drag a card, and the change is written straight back into the `.wurst` file — there's no separate database to lose track of.

## What it shows off

- Larger, structured JSON state saved inside the file
- Interactive drag-and-drop UI running entirely client-side
