**sneaky.wurst.png** is the `folio.wurst` example from above, ground through MeatGrinder's Ninja Pig mode. The result is a perfectly valid `.png` file — any image viewer opens it and shows a picture — but Wurster recognizes the app hidden inside.

## What it shows off

- Ninja Pig mode: embedding a `.wurst` inside a normal, undamaged image file
- The same portable-app guarantees, just wearing a disguise

<div class="callout">🥷 Try opening it in a normal image viewer first — it's a completely valid picture. Then open it with Wurster.</div>
