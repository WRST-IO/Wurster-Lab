**noted.wurst** is a tiny note-taking app that saves your notes right back into the `.wurst` file it was opened from — no server, no account, no sync step. Close it, email the file to yourself, open it on another machine: your notes are still there.

## What it shows off

- Writing user data back into a running `.wurst` file
- A single-file app that works completely offline
- Opening the same file identically across the Wurster Runtime and the Web/CDN runtime

```
$ wurster run noted.wurst
```
